# QuickVault 1.1.0

A polish and fix release on top of 1.0.0. Formats are unchanged: 1.1.0 opens
and writes the same vault, archive and snapshot formats as 1.0.0 (spec 0015).

This file is the release record that 0012 §3 asks for. Everything in the
[1.0.0 record](1.0.0.md) about signing, build inputs, the security status
and known limitations still applies; this file lists only what changed and
what was checked for it.

## What changed

- **Phone UI (plan 0068).** Quick-unlock settings show what is on, a real
  "Turn off" button and the other unlock method behind the master password,
  instead of "Turn on fingerprint unlock again". Long buttons wrap instead of
  running off the screen. The vault switcher lists its actions one per row.
  The create wizard no longer shows Android's private folder, which made it
  wider than the screen, and the unlock screen no longer scrolls sideways.
  Settings name the screen-lock policy and hide Android's private paths.
  Notices such as "Saved" go away by themselves (errors stay until
  dismissed). The hide button shows a crossed eye inside its countdown
  ring. The weak-password choices line up on phones. The move dialog says
  which group has no subgroups.
- **QR scan panel (plan 0068).** A scan panel always closes when its scan
  ends, and "Cancel scan" closes it at once. A screen redraw lost while
  nothing else changed (during or after a sync) is retried. The owner saw
  the panel stay open once after a fast sync; that case was not reproduced,
  and the fix closes the paths found that could cause it.
- **Windows startup (plan 0067).** The desktop app no longer starts with its
  window hidden: WebView2's mapped app URL is accepted for navigation, IPC
  and media requests by exact origin.
- **Alpine packages (plan 0066).** Separate `alpine-3.22` and `alpine-edge`
  packages, each installed and checked in a clean matching container before
  upload.

over it. Other artifacts are unsigned (owner decision, 0012 §3).

## Build inputs

- Toolchain: Rust 1.98.1 (`rust-toolchain.toml`), unchanged.
- Dependencies: unchanged since 1.0.0. The lockfiles differ only in
  QuickVault's own crate versions.
- Vendored: `dioxus-desktop` 0.7.10 with its local patch, changed for the
  Windows origin fix (`third-party/README.md`).

## Review status

Plans 0066, 0067 and 0068 have had no fresh-context review. By owner
decision they ship without one, like the UI plans listed in the 1.0.0
record. No independent security audit has been done.
